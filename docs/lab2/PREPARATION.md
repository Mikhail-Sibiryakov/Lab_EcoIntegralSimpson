## Проверка учебных примеров

Предварительная строгая C89-компиляция выявила несовместимости исходников уроков:
имя ERR_ECO_SUCCESES отсутствует в текущем SDK (используется ERR_ECO_SUCCESS),
а в учебных .c встречаются комментарии //.
Для IsEqualUGUID нужен -DUGUID_UTILITY, как в действующей сборке нашего компонента.
После исправления параметров проверки оставшиеся проблемы следует адаптировать
в копиях учебных исходников, не меняя SDK и исходный клон преподавателя.
Это ещё не проверка линковки, выполнения калькуляторов или свойств агрегирования.
Детальные результаты предварительной проверки включены в
[compatibility-check.json](compatibility-check.json).
