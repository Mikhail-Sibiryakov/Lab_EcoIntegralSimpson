## Наследуемые правила разработки

Применяются согласованные C89, запрет libc в собственном компоненте и C-клиенте,
получение сервисов через публичные Eco API и стиль кода из AGENTS.md.
Их источник — предыдущие инструкции пользователя и промпты, а не дополнительные
пункты нового четырёхстраничного задания.

Калькуляторные интерфейсы:

- IEcoCalculatorX: Addition и Subtraction;
- IEcoCalculatorY: Multiplication и Division.

Типы и сигнатуры берутся из SharedFiles InsideACOM. Контракт интегратора
не переносится автоматически на калькуляторные операции.

## Что сохраняется из первой работы

- адаптивный Симпсон;
- публичные методы integral/integralf/integrall;
- существующие IID/CID интегратора и опубликованные сигнатуры;
- поведение результата, оценки ошибки, callback и параметров точности;
- регрессионный UnitTest и независимое сравнение с mpmath;
- структура Eco Wizard и отчёт первой работы.

Новый численный метод, GUI, события, комплексные числа и другие дополнительные
возможности не входят в выбранный объём.
